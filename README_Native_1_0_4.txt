SmartScreen Capture & Recording V1.0 — Internal build 1.0.4

NEW: Video resolution Native (default), 1080p, 1440p. 720p removed.
Native records the original pixels of the monitor, region or selected window, with at most 1-pixel padding for even dimensions. If a selected window grows during a recording session, frames are fitted within the original dimensions; to change the native video dimensions, stop and restart recording.
Geometry: requested window height 810 pixels, constrained to available screen height minus 60 pixels (so 1024x768 remains usable).
Existing 1 GB splitting, auto-update, selected-window hover outline, screenshot captures and cx_Freeze configuration retained.
Build: run Build_cxFreeze_x64.bat or Build_cxFreeze_x86.bat on Windows.
Not validated on equipment PCs: Windows encoder, performance, 1440p and native playback.
